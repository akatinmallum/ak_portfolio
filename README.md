# Akatin Samuel Mallum — Internship Portfolio

A static, responsive, GitHub Pages-ready portfolio for internship applications through platforms such as Unstop.

## Included
- Internship-focused hero section
- About Me section
- Projects section with honest "In progress" labels
- Skills section
- Education section
- Resume / CV snapshot with browser print-to-PDF support
- GitHub and email CTAs
- Responsive mobile layout

## Files
- `index.html` — page content and resume print view
- `styles.css` — styling and responsive layout
- `script.js` — current-year footer and Print / Save CV action

## Deploy with GitHub Pages
1. Create a GitHub repository, for example `portfolio`.
2. Upload `index.html`, `styles.css`, and `script.js`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will provide your live Pages URL.
